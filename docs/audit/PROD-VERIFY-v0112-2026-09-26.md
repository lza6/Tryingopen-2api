## 4. 公网直连（绕过代理）——真实输出

### 4.1 连通性说明（必须如实记录）

- 本机环境变量存在 `HTTP_PROXY=http://127.0.0.1:10808` / `HTTPS_PROXY=...`。
- 复核使用 `curl.exe --noproxy "*"` 直连域名。**域名 SNI 直连 `https://try.hwhcie.bond/...` 在 TLS 握手阶段被中途重置（`curl: (35) Recv failure: Connection was reset`，HTTP 000）**，四次请求一致。这不是服务端 4xx/5xx，属于本机→公网链路上 SNI 直连被重置/拦截。
- TCP 443 可达：`Test-NetConnection try.hwhcie.bond -Port 443` → `TcpTestSucceeded: True`（RemoteAddress `20.204.27.154`）。
- 为取得真实应用响应（而不是把链路重置误报成服务宕机），改用 IP 直连 + `Host: try.hwhcie.bond`（`--http1.1 --tlsv1.2`）访问同一 443 端口 → 应用返回真实 HTTP 状态与 JSON。结果如下。
